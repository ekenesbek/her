# HerShared

`HerShared` is the canonical Swift package used by both the iOS app and the macOS desktop scaffold. It owns the backend contract, auth/session storage, and all shared models.

## Layout

```
her-ios/shared/
  Package.swift                          SwiftPM manifest, library product "HerShared"
  Sources/HerShared/
    Models/
      AuthModels.swift                   AuthUser, AuthSession
      Meeting.swift                      Meeting, TranscriptSegment, OutlineItem, MemoryCandidate, VoiceProfile, ChatMessage
      Subscription.swift                 Subscription (plan, recording quota, ask-AI flag)
    Network/
      BackendConfig.swift                Reads HER_BACKEND_URL, exposes loopback flag
      BackendError.swift                 LocalizedError for backend failures
      BackendClient.swift                BackendClient covering /v1/auth/*, /v1/auth/me, /v1/meetings, /v1/meetings/{id}, /v1/meetings/{id}/chat (GET/POST), /v1/subscription, /v1/voice-profiles
      ISO8601+Her.swift                  Shared JSONDecoder/JSONEncoder with backend date format
    Auth/
      TokenSource.swift                  Thread-safe singleton holding the active bearer token
      KeychainSessionStore.swift         Read/write `app.auth.session` keychain item, JWT exp parsing
      AppleSignIn.swift                  Cross-platform AppleSignInService (#if iOS / macOS)
```

## Endpoints

`BackendClient` exposes:

- `signInWithApple(identityToken:fullName:email:)` → `POST /v1/auth/apple`
- `signInWithGoogle(idToken:)` → `POST /v1/auth/google`
- `desktopSession(createIfMissing:name:email:)` → `POST /v1/auth/desktop` (loopback-only)
- `currentUser()` → `GET /v1/auth/me`
- `meetings()` / `meeting(id:)` → `GET /v1/meetings[/{id}]`
- `meetingAudioURL(meetingId:)` → URL for `GET /v1/meetings/{id}/audio`
- `chatMessages(meetingId:)` / `ask(meetingId:question:)` → `GET`/`POST /v1/meetings/{id}/chat`
- `subscription()` → `GET /v1/subscription`
- `voiceProfiles()` → `GET /v1/voice-profiles`

All requests authorize via `TokenSource.shared` (set by `AuthStore` / `KeychainSessionStore`).

## Consumers

- `her-ios/macos/HerMac.xcodeproj` links the local `../shared` package through the `HerShared` product. The generated macOS app target uses `HerShared` directly. Local typealiases in `Compat.swift` keep legacy `Her*` names working without churning the view file.
- `her-ios/frontend/ConversationSummarizer.xcodeproj` does NOT yet consume the package. See **iOS integration** below.

## iOS integration

The iOS target still uses its own duplicates of `AuthSession`, `AuthUser`, `TokenSource`, `AppleSignInService`, and `AuthClient`. To migrate, in Xcode:

1. **File → Add Package Dependencies… → Add Local…**
2. Select the folder `her-ios/shared`. Xcode shows the `HerShared` library product.
3. Add it to the `ConversationSummarizer` app target.
4. In each iOS source file that needs shared types, add `import HerShared`.
5. Delete the iOS-local duplicates in this order (build between steps to localize fallout):
   - `Features/Auth/AppleSignInService.swift` (use `AppleSignInService` from `HerShared`)
   - `Features/Auth/AuthClient.swift` (use `BackendClient` from `HerShared`)
   - `Features/Auth/AuthStore.swift` — keep the iOS-side `AuthStore` `ObservableObject`, but back it with `KeychainSessionStore` and `TokenSource` from `HerShared`. Drop the duplicate `AuthSession` / `AuthUser` struct definitions.
6. Optional: rename `MeetingSummary` to use `HerShared.Meeting` where it currently holds backend wire data. Local in-memory containers (`StoredMeeting`, `MeetingsStore`) can keep their richer iOS-only types and convert from `HerShared.Meeting` at the network boundary.

Adding the local package is the safe, one-shot operation. The iOS-local duplicate removal is intentionally incremental so the existing iOS target stays compilable at every step.

## macOS app integration

The current `her-ios/macos/` directory owns a real signed macOS Xcode app target generated by `scripts/create_xcodeproj.rb`. Use the Xcode project, not a SwiftPM preview, for normal desktop runs:

```bash
cd her-ios/macos
xcodebuild -project HerMac.xcodeproj -scheme HerMac -configuration Debug \
  -destination 'platform=macOS' -allowProvisioningUpdates build
open ~/Library/Developer/Xcode/DerivedData/HerMac-*/Build/Products/Debug/Her.app
```

If Swift files are added or removed under `Sources/HerMac/`, regenerate the project file list:

```bash
cd her-ios/macos
GEM_HOME=$HOME/.gem/ruby/2.6.0 ruby scripts/create_xcodeproj.rb
```

The generator overwrites `HerMac.xcodeproj`, wires `HerShared`, and reapplies the macOS bundle id, signing team, build settings, and entitlements.
